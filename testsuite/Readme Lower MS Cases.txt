We provide five sample cases for lower MS models that use different choices for surface boundary conditions equations of state (m0p1 feh+0.0 allard ZAMS; m0p3 feh+0.0 allard ZAMS; m0p1 feh+0.0 base ZAMS; m0p3 feh+0.0 scveos ZAMS; m0p3 feh+0.0 yaleeos ZAMS) in the test suite. We also include 3 models which include gravitational settling.

m0p1 feh+0.0 allard ZAMS uses the base physics suite, except for the usage of the allard model atmospheres for the SBC.
m0p3 feh+0.0 allard ZAMS uses the base physics suite, except for the usage of the allard model atmospheres for the SBC.
m0p1 feh+0.0 base ZAMS uses the base physics suite in a domain that is challenging for stellar models.
m0p3 feh+0.0 scveos ZAMS uses the base physics suite, except for the usage of the SCV EoS instead of the OPAL EoS.
m0p3 feh+0.0 yaleeos ZAMS uses the base physics suite, except for the usage of the Yale EoS instead of the OPAL EoS
Test_m1p0feh+0p0GS98_dif_TAMS solar mass model with gravitational settling, evolved to the TAMS
Test_m1p0feh+0p0GS98_dif0p75_TAMS solar mass model with 0.75* standard gravitational settling, evolved to the TAMS
Test_m1p4feh+0p0GS98_dif_TAMS 1.4 solar mass model with gravitational settling, evolved to the TAMS
