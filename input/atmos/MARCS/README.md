MARCS atmospheres (Gustafsson et al. 2008)

Each .tab file corresponds to a different atmospheric composition
and covers logg from -0.5 to 5.5 and logTeff from 3.398 to 3.903.
Some of these grids have uneven edges, but holes were filled via interpolation
so YREC should work for most cases.

The naming convention is 
z[Fe/H]\_a[$alpha$/Fe]\_c[C/Fe]\_n[N/Fe]\_o[O/Fe]\s+0.00_r+0.00.tab
where s, r refers to r- and s-element enhancement.
The reference solar composition is that of Grevesse, Asplund, and Sauval 2008 (Z = 0.0122)
[$alpha$/Fe] = [O/Fe] except for z+0.05_a+0.11_c+0.08_n+0.09_o+0.12_r+0.00_s+0.00.tab, 
which matchs GS98 solar abundances.

Using the same prescription as in the APOGEE MARCS atmospheres:
Models at logg >= 3.0 use plane parallel geometry and have a microturbulence of 1 km/s
Models at logg < 3.0 use spherical geometry for a 1Msun star and have microturbulence of 2 km/s

Note: the MARCS model atmospheres do not include dust, so they should not 
be trusted below 3000K.

[$alpha$/Fe] and [C/Fe] values range from -1.00 to +1.00 
for [Fe/H] values ranging from -2.50 to +1.00 in steps of 0.25. 

Some atmospheres with lower metallicities, with C/N cycling, and/or with [$alpha$/Fe] of $\pm 0.40$
See https://marcs.astro.uu.se/docs.html for a list of available composition.

Some of the model atmospheres (with lower [Fe/H], C/N cycling, and/or [$alpha$/Fe] of $\pm 0.40$)
used to generate the .tab files can be found on the MARCS website (https://marcs.astro.uu.se/docs.html).

Other model atmospheres were generated by Thomas Masseron using the same MARCS version 
as used to generate the model atmospheres used in the APOGEE 
Stellar Parameter and Chemical Abundance Pipeline (ASPCAP) (Jönsson et al. 2020).
